# ЮЖНЫЙ СОУС — ЭМО КОММЬЮНИТИ · промо

Интерактивный арт-объект, который притворяется странной игрой про картошку,
а в конце оказывается промо микстейпа.

Путь пользователя:

```text
СОУС → ВОЙТИ → глаз открывается → возьми → макни → съешь →
ЕЩЁ ×6 → картошка кончилась → а соус остался → глаз закрывается →
ты тоже не смог остановиться → лого ЮЖНЫЙ СОУС / ЭМО КОММЬЮНИТИ →
[ ПРЕСЕЙВ ] → [ ЕЩЁ РАЗ ] → всё сначала
```

Музыка не упоминается до финальной сцены. Так задумано.

---

## Запуск

Требуется Node 18+ (проверено на 22).

```bash
npm install
npm run dev      # разработка, http://localhost:5173
npm run build    # production-сборка в dist/
npm run preview  # раздача dist/, http://localhost:4173
```

> `preview` раздаёт `dist/`. После любых правок сначала `npm run build`,
> иначе увидишь старую версию. Вкладка с сайтом должна быть **одна** —
> две вкладки = два наложенных друг на друга эмбиента.

## Как это устроено

Вся драматургия — один конечный автомат в `src/App.tsx`:

```text
intro → eye-opening → table → no-fries → realization → eye-closing →
whisper → reveal → release → (ещё раз) → intro
```

Внутри `table` — подсостояние кусочка `FryState`:

```text
idle → holding → dipped → eating → idle (следующий цикл)
```

Гарды стоят в `grab` / `dip` / `eat`: взять вторую во время еды,
макнуть дважды или перескочить сцену случайным тапом — нельзя.
При этом отдельных boolean-флагов нет, всё выводится из `phase` + `fry`.

Управление — Pointer Events (`pointerdown/move/up`), одна система
для мыши и тача. Координаты нормализованные (0..1), сцена на весь экран.

## Структура

```text
src/
  App.tsx                 # state machine, тайминги перехода между фазами
  game.ts                 # Phase, FryState, CYCLE_HINTS, TOTAL_CYCLES
  config.ts               # RELEASE_URL, дата, обложка, лого, плейлист превью
  hooks/
    usePointer.ts         # pointer 0..1 + pressed, и для mouse, и для touch
    useSound.ts           # ван-шоты через Howler + эмбиент через Audio-синглтон
    usePreload.ts         # прелоад критических картинок (рука, еда, стол, обложка, лого)
    usePreviewPlayer.ts   # плейлист превью: play/pause, назад/вперёд, mute
  components/
    Intro.tsx             # чёрный экран: СОУС + [ ВОЙТИ ]
    Eye.tsx               # веки-шторки с кромкой + рандомное моргание 4–9с
    Scene.tsx             # стол, тарелка, соус, зоны тапа, кусок в руке
    Hand.tsx              # рука следует за pointer (spring-запаздывание)
    Final.tsx             # realization / whisper / reveal / release + обложка
  styles/
    globals.css           # чёрный фон, 100dvh, no-select, lid-стили
```

Стек: Vite + React + TypeScript + Framer Motion (движение) + Howler (ван-шоты).
Без Three.js / WebGL / Next.js — осознанно, ради веса и мобильных.

## Конфиг релиза — `src/config.ts`

```ts
export const RELEASE_URL = 'https://...';          // куда ведёт [ ПРЕСЕЙВ ]
export const RELEASE_SUBTITLE = 'ЭМО КОММЬЮНИТИ';
export const RELEASE_DATE = 'дата: ...';           // строка под CTA
export const COVER_URL = '/assets/release/cover.jpg';
export const LOGO_URL = '/assets/logo/logo.png';
export const PREVIEW_TRACKS = /* все mp3 из assets/release/preview-tracks */;
```

Превью: положи mp3 в `assets/release/preview-tracks/` — файл подхватится сам,
имя файла станет названием группы, порядок — по алфавиту. Трек в финале
подписывается как `группа - ?????` и крутится бегущей строкой; им управляют
кнопки `<<`, пауза/играть и `>>`. Копировать в `public/` не нужно: треки
импортируются через `import.meta.glob`.

## Добавить кадры руки

1. Положи png в `assets/hand/` **и** `public/assets/hand/`.
2. Добавь путь в `IMG` в `src/components/Hand.tsx`.
3. Добавь путь в `FILES` в `src/hooks/usePreload.ts`, чтобы кадр
   не мигнул пустотой в первый раз.

## Добавить / заменить звуки

1. Положи wav в `assets/sounds/` **и** `public/assets/sounds/`.
2. Ван-шот: создай `Howl` в `src/hooks/useSound.ts`, дёргай через `play('имя')`.
3. Требования к лупам: корректный WAV-заголовок (RIFF-размер = размер файла − 8),
   лучше pcm16; стык «конец → начало» склеить кроссфейдом ~0.5с, иначе щелчок.

## Добавить обложку / музыку

Обложка — любой jpg/png в `public/assets/release/` + путь в `COVER_URL`.
Не забудь копию в `assets/release/` и запись в `usePreload.ts`.

Треки — просто mp3 в `assets/release/preview-tracks/`, имя файла = группа.
Новые файлы и `public/` не требуют правок конфига.

## Звук: почему так

- Ван-шоты (`click/grab/dip/eat`) — Howler, с этим проблем не было.
- Эмбиент — **нативный `HTMLAudioElement`-синглтон на модуль**, рестарт
  по событию `ended`, без флага `loop`. Причина: зацикливание этого файла
  через WebAudio/Howler давало визг и наложение инстансов; синглтон
  физически не даёт создать второй поток. Компромисс: микропауза ~50–100мс
  каждые 9.2с вместо бесшовности (`ponytail:`-комментарий в коде).
- Mute-кнопка (`звук: вкл/выкл`, незаметная, справа внизу) глушит ван-шоты,
  эмбиент и превью-треки.
- Автоплей-политику обходим честно: весь звук стартует после клика «войти».

## Мобильное и перфоманс

- `100dvh`, `touch-action: none`, выключены overscroll, селект текста,
  драг картинок, хайлайт тапа.
- Рука следует за pointer через motion values + spring, а не через
  React state на каждое движение — лишних ре-рендеров нет.
- Интерактивные зоны крупные (кнопки с паддингами), целиться пальцем
  в пиксель не нужно.
- `prefers-reduced-motion` — упрощённые эффекты.

## Если что-то не так

| Симптом | Причина и лечение |
|---|---|
| Видна только кнопка, сцены нет | не подключён CSS / старая сборка → `npm run build`, одна вкладка |
| Эмбиент визжит или двоится | висит вторая вкладка или старый preview → убить процесс, закрыть все вкладки, `preview` заново |
| Новый ассет не грузится (404) | забыта копия в `public/assets/` → скопировать, `build` |
| Кадр руки мигает при первом показе | кадр не в `usePreload.ts` → добавить |
| Звук не стартует | браузер режет автоплей до жеста → всё запускается только после «войти», так и должно быть |
